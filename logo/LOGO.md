# Kron logo

The mark is `{K}`: the letter of the language held between braces -- the
blocks of Kron, and code kept safe inside them.

## Files

| file | use |
|---|---|
| `svg/kron-logo.svg` | the full logo, mark and name, on light backgrounds |
| `svg/kron-logo-dark.svg` | the same, on dark backgrounds |
| `svg/kron-mark.svg`, `svg/kron-mark-dark.svg` | the mark alone, 48 px and up |
| `svg/kron-mark-small.svg`, `svg/kron-mark-small-dark.svg` | the mark alone, 32 px and below: heavier strokes so it still reads |
| `svg/kron-wordmark.svg`, `svg/kron-wordmark-dark.svg` | the name alone |
| `svg/kron-icon.svg`, `svg/kron-icon-small.svg` | the app icon: the mark on a dark rounded square |
| `png/kron-icon-16.png` .. `png/kron-icon-512.png` | the app icon as images; 32 px and below use the small mark |
| `png/kron-logo.png`, `png/kron-logo-dark.png` | the full logo as images, 1600 px wide |
| `kron.ico` | the Windows icon, 16 to 256 px |

The name is drawn as shapes, not set in a font, so it looks the same
everywhere. Every stroke is 22 units thick, and the K of the mark is the same
K as in the name.
